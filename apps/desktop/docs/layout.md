# Desktop 布局

本页是 Desktop 的布局与滚动指南，补充 `apps/desktop/src/app/layout-scroll-contract.test.ts` 的自动
契约。它描述用户可观察的布局边界，不维护视图数量或完整导航 inventory。

## 自动契约

- 看板横向溢出只由看板滚动容器承载，页面本身不产生第二条横向滚动。
- 看板列保持 `min-h-0`、`overflow-hidden`，正文在列内纵向滚动。
- 任务详情面板的 chrome 固定，正文区域独立滚动。
- 侧边栏宽度过渡期间裁切内容，过渡结束后再显示展开标签。

## 窄窗口人工冒烟检查

在 390—480 像素宽度运行 Desktop Web shell，并连接本地 host，准备足够多的任务使列发生溢出：

- 看板横向滚动：看板可以横向滚动，最后一列可访问，页面没有额外横向滚动条。
- 列内纵向滚动：高列只在正文区域纵向滚动，列标题保持可见。
- 任务详情正文滚动：打开任务详情后，标题保持可见，正文可滚动，面板不超出视口。
- 侧边栏过渡与裁切：收起或展开侧边栏时，标签不遮挡主标题栏，图标按钮持续可用。
