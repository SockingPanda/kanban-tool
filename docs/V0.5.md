# V0.5 Release Notes

V0.5 把文档包推进为可运行的本地 Kanban / durable work queue MVP。

## 范围

已实现：

- Rust workspace：`kanban-core`、`kanban-sqlite`、`kanban-cli`。
- SQLite 初始化：`kb init`、默认 board、默认 columns、schema migration。
- Task CRUD：`kb task create/list/show/update/archive`。
- Event 记录：创建、更新、状态转换、依赖变更均写入 `task_events`。
- 状态机 MVP：promote、claim/start、heartbeat、done、review、block、unblock、reclaim、archive。
- Dependency MVP：add/remove/list、直接/间接环检测、依赖未完成时 child 降级、parent 完成后 child promotion。
- Run / dispatcher MVP：`kb dispatch --once` claim ready task、执行本地 command、写 run、写日志、按成功/失败策略收尾。
- CLI JSON：核心命令支持 `--json` 机器可读输出。

暂未进入 V0.5：

- 常驻 dispatcher loop 的服务化管理。
- Web API / Web UI。
- comments / attachments / labels CLI。
- doctor / backup / export。

## 验证

已通过：

```bash
cargo fmt --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

已跑 CLI smoke：

```bash
kb --db /tmp/kb.db init --json
kb --db /tmp/kb.db --json task create "v0.5 smoke" --description "run worker"
kb --db /tmp/kb.db task list
kb --db /tmp/kb.db --json dispatch --once --command 'echo smoke=$KB_TASK_ID'
kb --db /tmp/kb.db --json task show <task_id>
kb --db /tmp/kb.db runs <task_id>
```

结果：SQLite `PRAGMA integrity_check` 为 `ok`，smoke task 状态为 `done`。
