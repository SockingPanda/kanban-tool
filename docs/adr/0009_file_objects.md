# 0009 文件身份与对象关联分离

状态：已采纳。

同一文件可能属于多个对象，附件删除也不能误删其他对象正在使用的内容。因此文件内容使用
不可变 blob，文件对象保留原名和内容身份，所属关系使用普通 `file.attachment` 边。

旧任务附件入口适配同一模型，旧表停止接受写入。解除关联只删除对应关系，文件对象和内容
保留。文件发布先于 metadata commit；发生取消或不确定提交时，保留可能已被引用的 blob，
使用原身份核对结果。自动 GC 和预览不属于当前能力。

数据库备份和 portable metadata 不能替代附件目录备份。恢复必须同时核对数据库引用、存储
路径、内容长度与 hash，禁止由客户端任意指定本机读写路径。

详细调用边界见 [service 文件指南](../../crates/kanban-service/docs/files.md)。
