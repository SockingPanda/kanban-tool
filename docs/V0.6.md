# V0.6 Invariant Hardening Notes

V0.6 focuses on durable queue correctness. It does not add broad product surface area; it tightens reclaim, dependency recomputation, migration validation, query boundaries, and local diagnostics.

## Implemented scope

- `reclaim_expired` now re-reads each candidate inside `BEGIN IMMEDIATE` before mutating it.
- Reclaim task updates include an expiry guard when the caller is not forcing reclaim.
- Manual reclaim also validates a fresh task snapshot inside the write transaction.
- Removing a dependency recomputes eligible child tasks and promotes them when prerequisites are now satisfied.
- Explicit initial `ready` status now requires a non-empty description and no future `scheduled_at`.
- Explicit initial `scheduled` status now requires `scheduled_at`.
- Initialization records a migration checksum, validates migration identity, sets `PRAGMA user_version`, and checks critical schema shape.
- API task list filtering, sorting, limits, and offsets now run in SQLite instead of after full board materialization.
- API event `after` and `limit` boundaries now run in SQLite.
- `kb doctor` reports SQLite integrity, migration/user version, expired running tasks, running tasks without active runs, and orphan running runs.
- `block`, `archive`, and shared status updates use guarded writes inside immediate transactions.

## CLI

```bash
kb doctor
kb --json doctor
```

JSON output includes:

```json
{
  "ok": false,
  "integrity_check": "ok",
  "migration_version": 1,
  "user_version": 1,
  "expired_running_tasks": 1,
  "running_tasks_without_active_run": 0,
  "orphan_running_runs": 0
}
```

`doctor` is read-only. It does not reclaim, repair, migrate past known versions, or mutate task state.

```bash
cargo fmt --check

cargo clippy --workspace --all-targets -- -D warnings
```

## Out of scope

- Large `service.rs` module split.
- Full multi-version migration framework beyond validating `001_initial`.
- Backup/export/checkpoint commands.
- DB actor or `spawn_blocking` API execution model.
- Desktop operator-console enhancements.
- Drag/drop UI.
